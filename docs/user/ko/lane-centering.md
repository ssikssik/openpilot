# 차선 중앙 유지 보정

carrot-dev의 `ej > 차선 중앙 유지`에서 설정합니다. 레인리스 모드에서 모델 경로가 양쪽 차선의 중간을 벗어나면 중앙 방향 곡률을 추가합니다. 차선에 가까워졌을 때 밀어내는 기존 클램프와 함께 동작하며, 최종 횡가속도·횡저크·곡률·조향각 제한은 그대로 적용됩니다.

| 설정 | 기본값 | 범위 |
|---|---|---|
| `LaneCenterEnable` 중앙 유지 사용 | 켜짐 | 끔·켬 |
| `LaneCenterMinSpeed` 최소 작동 속도 | 0 = 추가 제한 없음 | 0~150km/h |
| `LaneCenterThreshold` 시작 거리 | 20cm | 5~50cm |
| `LaneCenterGain` 보정 게인 | 10 = 1.0배 | 0~20 = 0~2.0배 |

시작 거리를 줄이면 작은 경로 편차에도 보정합니다. 게인을 높이면 보정이 강해지며, 0이면 보정을 끕니다. 설정은 저장 후 제어 루프에서 반영되며 재부팅이 필요하지 않습니다. 편차가 임계값을 넘은 상태가 새 카메라 프레임 기준으로 0.3초 이어져야 보정을 시작하고, 시작 후 0.4초에 걸쳐 보정 강도를 올립니다. 같은 프레임을 제어 주기마다 다시 세지 않으며, 프레임이 0.15초 넘게 끊기면 확인을 처음부터 다시 합니다. 편차가 임계값의 절반 아래로 줄거나 방향이 바뀌면 종료합니다. 이 편차는 모델 경로와 모델 차선 중앙의 차이이며 실제 차량의 횡방향 위치를 직접 측정한 값이 아닙니다.

양쪽 차선 인식 확률이 0.5를 넘어야 시작하며 0.3 아래면 해당 인식을 해제합니다. 5km/h 이하는 보정하지 않고 5~10km/h에서 점진 적용합니다. 방향지시등, 차선변경 상태 또는 자동 회전 신호가 있으면 보정을 중단하고 종료 후 2초 대기합니다. `LaneCenterMinSpeed`가 0보다 크면 실제 차량 속도가 그 값 이상일 때만 보정합니다. 설정 끔, 게인 0, 최소 속도 미만, 차선 누락·비정상 입력에서는 보정 목표가 0이 되고, 이미 적용 중인 보정은 아래 변화율 제한에 따라 서서히 줄어듭니다(즉시 0이 되지 않습니다). 레인풀과 VW MEB 전용 분기는 적용 대상이 아닙니다.

1초 앞의 5~30m 지점을 사용합니다. 추가 보정 자체는 횡가속도 1.5m/s² 및 곡률 0.02m⁻¹ 이내이며, 허용된 보정의 변화율은 0.01m⁻¹/s로 제한합니다. 차선 미인식 때 조향을 대신 수행하는 기능이 아니며 실차 주행 성능은 아직 검증하지 않았습니다.

## 중앙 위치 급변 보호

약 0.32초의 카메라 프레임 이력에서 모델 경로는 비슷한데 차선 중앙·폭이 갑자기 바뀌면 중앙 보정을 일시 중단합니다. 같은 프레임을 제어 주기마다 새 샘플로 세지 않습니다. 최소 1초 대기하고 최근 0.2초 이상 차선 폭·중앙·인식 확률이 안정된 경우에만 복귀합니다. 중단 시 추가 중앙 보정 목표는 0이 되고 기존 변화율 제한에 따라 줄어들며, 기존 최종 곡률 완화 처리는 유지됩니다.

## 장애물 회피 중 차선 보정

`LaneAvoidanceMode`는 K8 하이브리드와 KIA EV4에서 제공하는 시험 기능입니다. EV4 실차 검증은 미완료입니다. `0`은 끔, 기본값 `1`은 후보 기록만, `2`는 실험 적용입니다. `2`에서는 ClampEnable도 켜져 있어야 하며 레인리스의 중앙 보정만 줄입니다. 레인모드 경로·기존 클램프·최종 조향 제한은 변경하지 않습니다.

전방·코너 레이더가 같은 차로 가장자리의 정차·서행 차량을 교차 확인하고, 이미 모델이 만든 경로에 같은 차로 안에서 비켜 갈 여유가 있을 때만 장애물 쪽으로 당기는 중앙 보정을 줄입니다. 자체 회피 경로를 만들지 않습니다. 적용 속도는 약 18~64.8km/h이며, 운전자 조향·가속·제동, 방향지시등, 차선변경, 자동 회전, 주변 차량·사각지대, 오래되거나 잘못된 입력은 감지/적용을 제한합니다. 기본 기록 모드는 조향 보정을 바꾸지 않습니다. 실차 동작은 검증하지 않았으며 적용 모드는 통제된 시험 환경용입니다.

## 카메라 오프셋

`ej > 카메라 오프셋`의 `CameraOffset`(기본 0=끔, -50~50cm)은 레인리스에서 차를 옆으로 일정량 미는 곡률을 더합니다. 양수는 오른쪽, 음수는 왼쪽입니다. 차의 실제 위치를 재서 맞추는 기능이 아니라, 1초 앞(5~30m) 지점에서 설정 거리만큼 비키는 데 해당하는 고정 곡률(설정 거리×2의 횡가속, 30cm면 약 0.6m/s²)을 모델 곡률에 더합니다. 횡가속 1.5m/s²·곡률 0.02m⁻¹ 상한과 0.01m⁻¹/s 변화율 제한은 중앙 유지와 같습니다.

왼쪽 차선이 보이고, 오른쪽 차선이 안 보이거나 더 왼쪽 차선이 안 보일 때(제일 왼쪽 차로)에만 작동합니다. 오른쪽 차선만 보일 때는 연석 쪽으로 밀 수 있어 제외합니다. 이 조건이 1초 유지되어야 켜지고, 조건이 사라진 뒤 2초가 지나야 꺼집니다. 5~10km/h 점진 적용, 차선변경과 종료 후 2초 대기는 중앙 유지와 같습니다. 레인모드에는 적용하지 않습니다.

중앙 유지와 함께 켜면 서로 반대로 당길 수 있으므로 하나만 쓰는 것을 권장합니다. 실차 주행 성능은 검증하지 않았습니다.
